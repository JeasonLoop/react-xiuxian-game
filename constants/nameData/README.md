# 仙侠命名词库（节选）

来源：https://github.com/hythl0day/random_chinese_fantasy_names
许可：MIT License (c) 2021 Hetu (河图)

## 说明
- 按原库 7 档稀有度（common/uncommon/rare/epic/legendary/mythic/exotic）原样收录
- 使用时映射到本项目 4 档：common/uncommon→普通、rare→稀有、epic/legendary→传说、mythic/exotic→仙品
- 仅取装备/材料/丹药/生灵命名相关子集；功法/秘籍/门派/地点语料待后续扩容时取用
- 生成仍走项目内确定性规则（index 取模/固定专名表），不在运行时引入该 npm 包
